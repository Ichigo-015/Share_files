# Share Files — P2P ファイル共有アプリ

C# / WPF (.NET Framework 4.7.2) で作る、ピアツーピアのファイル共有アプリです。
1 つのアプリが「送信(クライアント)」と「受信(サーバー)」の両方を兼ね、
同一ネットワーク上の相手と直接ファイルをやり取りできます。

## 主な機能

- **受信(待ち受け)**: 指定ポートで待ち受け、複数ファイルをまとめて受信
- **送信(接続 → 選択 → 送信)**: 相手の IP に接続し、選択した複数ファイルを送信
- **複数ファイルの一括転送**(1 接続で何度でも送信可)
- **進捗バー** とステータス表示
- **保存先フォルダの変更**(既定は `ダウンロード\SharedFiles`)
- 受信ファイル一覧の表示(ダブルクリックで開く / フォルダを開く)
- 同名ファイルは `(2)` などを付与して自動リネーム保存

## 使い方

2 台(または同一 PC で 2 つのインスタンス)で実行します。

### 受信側

1. 「待ち受けポート」を確認(既定 `1145`)
2. **待ち受け開始** を押す
3. 必要なら **変更** で保存先フォルダを選ぶ

### 送信側

1. 「相手の IP」に受信側の IP アドレスを入力(同一 PC なら `127.0.0.1`)
2. **接続** を押す
3. **ファイルを選択** で送りたいファイルを選ぶ(複数可)
4. **送信** を押す
5. 終わったら **切断**

## 通信プロトコル

1 セッション = 1 バッチ。TCP ストリーム上を以下の順で流します。

```
[Int32  ファイル数]
  ファイルごとに:
    [String ファイル名]      ... BinaryWriter 形式(長さ前置き UTF-8)
    [Int64  ファイルサイズ]
    [byte[] 本体]            ... 上記サイズ分の生バイト列
```

同じ接続で複数バッチを連続送信でき、受信側は接続が切れるまでループで待ち受けます。

## ビルド / 実行

Visual Studio 2022 で `Share_files.slnx` を開き、ビルドして実行します。
(`.NET Framework 4.7.2` をターゲットにしています)

## 注意

- 別 PC と通信する場合は、受信側 PC のファイアウォールで該当ポートの受信を許可してください。
- LAN 内での利用を想定しています(暗号化は行いません)。
